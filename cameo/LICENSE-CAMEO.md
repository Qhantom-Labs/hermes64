# Cameo pack notice (cameo_visor_01)

This optional pack contains a character model based on the likeness of **Teknium**. The likeness is included
with Teknium's consent, as relayed by Dylan (Qhantom Labs), so that people can make games with Hermes64 that
feature him.

**You may** use the cameo character in games and videos made with Hermes64, including sharing and publishing
those games.

**You may not** use it:

- to impersonate Teknium, or to put words in his mouth as if he said them;
- to suggest that he, Nous Research or Qhantom Labs endorse a game, product or message;
- in misleading, deceptive, defamatory, hateful or sexual content, or anything that mocks him.

The model files themselves are covered by the repository licence (MIT, see `../LICENSE`); this notice adds the
conditions above for the likeness. Questions about the likeness go to Qhantom Labs, not to Teknium.

**Removable in one step.** The core plugin works without this pack. In a plugin install, delete the `cameo/`
folder. In the repository, run `python3 -B -m tools.catalog remove-cameo`, which deletes the folder and rebuilds
the asset catalog and the hub registry without it.
