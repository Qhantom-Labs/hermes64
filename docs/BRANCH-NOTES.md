# Experimental platforms branch

This is experimental, post-submission development, not the frozen hackathon entry. It combines the Linux/Windows
platforms work with the catalog-review child-environment and routing fixes. Do not merge it without review.

Windows is **built and simulated, not verified**. Linux authoring is **implemented behind bubblewrap, not verified**.
No native Windows or Linux acceptance receipt exists for this candidate, and the owner has not tested it. macOS
checks and simulated-platform tests do not change those limits. Use [PLATFORM-EVIDENCE.md](PLATFORM-EVIDENCE.md),
[WINDOWS-TEST-SHEET.md](WINDOWS-TEST-SHEET.md) and [LINUX-TEST-SHEET.md](LINUX-TEST-SHEET.md) for the remaining gates.
