# Experimental styles branch

This is a post-submission experimental styles branch, not part of the hackathon submission pin. Windows and Linux
have not been verified on real machines. Do not merge without review.

It combines the off-catalogue style-derivation work with the catalog review's child-environment and other-engine hint
fixes. Existing style results are limited to the recorded local direct-path runs; they are not visual approval,
real-platform acceptance, or end-to-end model/agent evidence.
