# Catalog disclosure draft — NOT SUBMITTED

Hermes64 is a native Python Hermes plugin for authoring N64-era-style 3D adventures from source specs and theme packs. It uses public `ctx.register_tool`, `ctx.register_command` and read-only `ctx.get_config` surfaces. The package declares its 13 tools exactly; it registers no hooks, middleware, core overrides, provider, login backend, telemetry or privileged host capability.

**Local execution:** Python STORY commands, Blender headless build scripts and Godot headless/GUI runtime commands run as local subprocesses. Blender and Godot are separate existing programs, not bundled binaries or "our engine". No shell-string execution, downloads, package installation, AI mesh/image service or paid API is included. Executable paths and the trusted assembled component bundle are owner-selected settings. Tool callers cannot supply shell flags or arbitrary executable scripts. Calls have closed stdin, bounded output and timeouts; the GUI is an explicitly requested, bounded foreground preview, not a long-running background service.

**Optional Blender (NOBLENDER lane):** opt-in `builder=python` / `auto` builds static kits using an existing `python_path` with numpy; the GLB container writer itself is standard-library-only. This removes Blender subprocesses from that path, not all subprocesses. Verified prebuilt assets/cast remain reusable without Blender. New character rig/skin/animation generation and legacy Cycles tools still require Blender. The default remains Blender pending strict parity; see docs/NOBLENDER-PARITY.md. No dependency is installed automatically.

The staged reference-to-pack developer workflow also replaces Blender measurement/proof calls with Python workers, and uses existing Godot for runtime proof or an explicitly labelled lower-fidelity Python preview when Godot is absent. JPEG requires Pillow in the selected interpreter; 16-bit PNG is refused. It preserves `draft_unapproved`, private-reference/provenance guards and no-automatic-approval semantics. Refpack and the read-only doctor have **not** been newly registered as Hermes tools in this lane; Main must wrap any future registration in the existing project Runner boundary. Direct developer CLI invocation is not a claim of plugin sandbox containment. Godot proof may add a renderer child, so reduced Blender use is not a claim that every workflow has fewer total processes.

**Reads:** the selected game's source/spec/save/report/pack data, the trusted installed component bundle and its manifests/templates, executable discovery via PATH/default engine locations, and system/runtime libraries needed by those programs. No credential stores, auth.json, .env files, browser profiles or keychains are read by plugin code. Child environment is scrubbed, but the macOS sandbox is a write/network boundary, **not a confidentiality/read sandbox**. Do not point settings at an untrusted binary or bundle.

**Writes:** only the selected game directory under an existing owner-chosen `projects_root`: source spec; pack snapshots/custom pack data; immutable build/edit candidates; diff/proof/benchmark/migration reports; optional migrated saves; asset exports and sidecars; copied Godot runtime project and its local cache; child HOME/temp/cache/config-data directories; bounded full-response files; current revision pointer and operation lock. It does not write into its installed plugin tree, Hermes config/skills/memory, another project, or plugin_data_dir. The sandbox permits the system null device `/dev/null` for process I/O, not persistent outside-project output.

**Network:** none in plugin code. Every child is wrapped in a macOS system policy denying network access and outside-project filesystem writes. Hosts without that wrapper fail closed. No telemetry, self-update, remote code loader, OAuth flow or stored credentials. There are no interactive child prompts and no inherited Hermes YOLO/approval environment flags. This plugin does not disable or auto-approve Hermes controls.

**Limits:** path guards reject absolute/traversal data paths, symlinks, hardlinks and special files. This is not a guarantee against a same-user concurrent filesystem attacker, compromised trusted engine or host administrator. Abstract story proof does not prove 3D movement, presentation, copyright clearance or creative quality. Pack data validation is not rendered style acceptance. Measured KITS 3.1 integration and normalized Godot proof replay have run in the assembled tree. Asset validation remains narrower than perceptual style approval, physical navigation or actual rig/animation acceptance. See RESULT.md for exact evidence and unverified claims.

**Admission status:** no public repository, pin, catalog PR, validation/scan, maintainer review or tested SemVer floor is claimed. The package is not installed or enabled in any Hermes profile by this work. The full assembled and pinned tree must be validated and scanned before an owner-authorized submission.
