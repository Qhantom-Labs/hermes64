# SHIP disclosure additions — local only, not submitted

Append/reconcile this with `docs/DISCLOSURE.md` when Main registers the three tools (13 baseline tools become 16 before other lanes' additions). These files do not install or activate a plugin/profile.

**Processes:** physical probes run installed Godot 4.6.2 at fixed 60Hz, headless by default, optionally rendered. Demo runs the existing STORY Python compiler/checker and Blender asset builder, then the probe and web exporter. Export invokes a project-local intact copy of the installed Godot editor and locally ad-hoc signs only its generated macOS app using `/usr/bin/codesign --sign - --timestamp=none`. No keychain identity, notarization, downloader, uploader, new dependency or external API is used. Existing argv-only subprocess bounds, scrubbed environment and no-network/project-write sandbox remain in force.

**Reads/writes:** read the selected project, trusted installed bundle, public bound media, installed engine and previously approved templates. Write playtest evidence, runtime staging, export editor/templates/cache, portable media closure, licenses, target builds, inventories and ZIPs inside the selected project. Exported games write only normal local Godot `user://` save data (game-specific directory; web uses the browser's local storage/IndexedDB). The code does not read personal browser profiles or credentials. The existing sandbox is not a confidentiality/read sandbox.

**Template installer exception:** `tools/ship_templates.py` is a separately invoked maintainer helper, not a public tool. Only with explicit owner approval, it verifies an already downloaded official archive and writes the five enumerated files to the standard 4.6.2.stable user-template directory. Its receipt lists exact paths, sizes and hashes. No network or other install directories are involved.

**Browser developer verifier exception:** `tools/ship_web_smoke.py` serves the chosen web export on loopback only and launches installed Chrome in a fresh Hermes scratch profile. It sends actual keyboard events, checks receiving game events and saves a screenshot and console receipt. It stops both processes afterward. Its separate outer macOS sandbox permits loopback/local Unix IPC and writes only to that temporary profile and evidence output; Chrome's inner sandbox is disabled because macOS disallows nested Seatbelt initialization. This verifier is not a public tool and does not use a user's existing browser session. Chrome's OS stderr and page console errors are retained separately.

**Privacy boundary:** source and bindings flagged private/internal/restricted are refused. Only manifest-admitted public character media and hash-verified dependencies are copied; absolute source-home paths, cameo identifiers/private metadata and internal source directories are excluded. Known upstream virtual filesystem/diagnostic prefixes in the official templates are narrowly relocated with byte-length-preserving substitutions, with notices retained; this does not excuse user-private references. Remaining final bytes and nested archives are scanned fail-closed. Structured/byte scans do not prove arbitrary content contains no personal information or that all intellectual-property rights are cleared.

**Claims:** logical proofs, bounded real physical navigation, rendered frames and build receipts are separate evidence. Reports cannot judge fun, production proximity rules, arbitrary-geometry reachability or style approval. Headless performance is throughput, not display FPS. Memory/resource monitors and exit leak diagnostics are not a universal leak proof. Native macOS headless boot does not establish other-device/Gatekeeper acceptance. Windows executables are built but **UNVERIFIED on Windows**. No public upload, catalog submission or cross-machine certification is implied.
