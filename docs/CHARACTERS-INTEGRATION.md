## Binding and runtime design

- `tools/import_characters.py`: fail-closed manifest count/identity/gate/hash/byte checks; independent GLB mesh, skin, joint and clip inventories; body **<700** and each separately named prop **<=200**; STEP-key enforcement; output writes only after the entire source/binding set validates.
- `characters/manifest.json`: the 28 public records with preserved source fields, measured counts, original SHA-256 and source-manifest hash. The restricted record, including its params and restriction flags, lives only in ignored `characters/internal/manifest.json`. Unchanged source GLBs, not lossy derivative exports.
- Root `bindings.json`: exact selectors plus `character_id`, source rig, animation/bone inventory and nested fallback. Native shader colour handling is `linear_gltf`, not the kit meshes' unusual display-space sRGB8 convention.
- `characters/presentation.json`: additive staging for every story room and every original animal, plus closer Last Light interior cameras. No new story NPCs, actions, guards, endings, or save fields. Last Light's otherwise empty rooms show the actual protagonist, not invented residents.
- `characters/integration.py`: `CharacterComponents.prepare_runtime` first calls the original trusted-copy preparation, then `stage_runtime` installs root bindings and selects the owned entry scene **only in the generated runtime**. Environment assets, room builder, rig, shaders, UI, native capture passes and core state machine remain the original code.
- `runtime/godot/actors/assets.gd`: derived resolver. GLBs use runtime GLTFDocument loading, exact hashes and the actual source rig. Missing optional real files can use the original fallback; a wrong hash produces a missing/error diagnostic instead of quietly falling back.
- `actors/character.gd`: separate manual animation clock, floor-origin/metre scale, +Z model facing and a 12-triangle translucent shadow fan. Source clips are 12 fps STEP; playback is sampled on a **15 Hz held clock**, with duplicate poses where the source has no extra key. This does not invent 15 unique source poses per second. World motion remains with the physics controller. The native test measures about 2.4 metres over 60 physics frames at both 15 and 5 pose fps.
- `actors/bridge.gd`: player walk/idle, NPC dialogue talk, moving animal followers, protagonist staging and the +Z-model versus -Z-controller orientation correction. Face atlases use explicit scale plus Blender-bottom-up/glTF-top-down row conversion. Talk alternates talk_a/talk_b cells where provided; no blendshapes or fabricated facial rig.
- Silver hoods: current source GLBs mark `chrome_env` but omit its texture binding. Resolve the existing pack's `env_chrome` sphere map. If a future source embeds one, prefer it. The black **face void** is intentional; it is distinct from a missing/black chrome hood.
- Textures: remove image mipmaps and derive an actor-only shader from the current room shader, forcing nearest sampling and adding atlas UV scale. This retains room-look fog/light/grade without editing shader files or changing global environment filtering.
