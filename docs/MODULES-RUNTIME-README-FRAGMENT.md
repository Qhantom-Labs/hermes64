## Gameplay modules (scoped native candidate)

STORY 1.2 has a native Godot candidate for bounded melee arenas, ability/key-gated outdoor regions and timed on-foot courses. Modules are supported only when the **exact build's playtest report is PLAYABLE**, within the scope printed in that report. A bot completion is not proof of human winnability or balance.

The Reedland mixed game passes headless physical playtesting and its N64-era image style/geometry gates. Its latest rendered run is **ROUGH** because the measured steady-frame budget is exceeded; it is not an all-green rendered release. Combat clips are explicitly labelled prototype poses until original art is bound. Controls/art composition and human review remain pending.
