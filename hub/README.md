# Hermes64 Hub registry (bundled seed)

This folder is a complete Hub registry, laid out to become a public repository unchanged:

| Path | What |
|---|---|
| `index.json` | Schema `hub/1.0.0`: every entry with licence, tier, compatibility, archive sha256 and per-file hashes; `entries_sha256` guards against hand edits |
| `previews/` | 160x120 PNGs cropped from existing in-game captures and kit renders (no picture means none exists yet) |
| `site/` | Offline browse page: open `site/index.html` (no network, no framework) |
| `archives/` | Not committed. Installs rebuild bundled archives from the plugin's own files and check the sha256; run `python3 -B -m tools.hub archives` to write them for publishing |
| `drafts/` | Not committed. Where pull requests drop `/hermes64 hub publish` drafts for `tools.hub add-draft` |

Generated by `python3 -B -m tools.hub build`; `python3 -B -m tools.hub check` fails on any drift. Do not edit
`index.json` by hand: the plugin refuses an index whose `entries_sha256` does not match. Policy, contribution steps and
takedowns: `docs/HUB.md`.
